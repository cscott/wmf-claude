- Phabricator and Gerrit MCP servers run on the host and reach this sandbox through a proxy, so they carry the engineer's credentials and you never see them. Their tools arrive under their own names: use mcp__phabricator__phabricator_get_task to verify Bug: references in commit messages, and mcp__gerrit__get_commit_message to preserve Change-Id when amending Gerrit-pushed commits. Only read-only tools are offered — Gerrit's writing tools (abandon_change, post_review_comment, create_change, ...) are deliberately not served here, so post review comments by telling the engineer what to post, not by calling a tool. If the tools are absent (the host had no servers registered), read the task or change over the web instead, and recover a Change-Id from `git log` rather than guessing one.
- Verifying a change against the local wiki needs no launcher flag here: the wiki runs inside this sandbox, on this sandbox's own loopback. Start it with `composer serve &` in the core checkout, then `curl "$MW_SERVER/index.php?title=Special:Version"` (MW_SERVER defaults to http://localhost:4000). The server can take a few seconds to answer the first time: retry the curl for a while before you read a `000` (connection refused) as a failure. Prefer curl + `/api.php` for HTTP status, redirects, rendered HTML, and API responses — it loads no MCP and its output is discardable. There is no browser MCP in this backend, so you cannot look at a page yourself: pixels and the accessibility tree are not available, and you must say so rather than substituting a guess. A real browser is still available to drive: run `mw-install-browser` once, then the selenium harness (`npx wdio ./tests/selenium/wdio.conf.js --spec <file>`) runs headless Chrome, which gives you real interaction, console errors, and a screenshot of each failure in `tests/selenium/log/`. Ask the engineer to look in a browser when the question is about how a page appears. See ~/MEDIAWIKI-TESTING.md for the test harnesses and /wmf-claude:manual-test for the parts of the ladder that do apply.
